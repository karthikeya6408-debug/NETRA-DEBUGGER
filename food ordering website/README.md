# Food Zone

A simple responsive food ordering webpage made using HTML and CSS only.

## Files
- `index.html` - webpage structure
- `style.css` - page design and responsive layout

## Features
- Header and navigation bar
- Welcome section with an image
- Four food categories
- Six restaurant cards with images
- Flexbox for navigation and food categories
- CSS Grid for restaurant cards
- Hover effect and media queries

## How to open
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. Keep internet access on because the pictures load from Unsplash.

## Test screen sizes
Use browser developer tools to test:
- Mobile: 375px
- Tablet: 768px
- Desktop: 1280px

No JavaScript is used.
