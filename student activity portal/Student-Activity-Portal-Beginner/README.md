# Student Activity Portal

A simple beginner-level HTML, CSS and JavaScript project for Lab Experiment 1.

## Files
- `index.html` - webpage structure and student registration form
- `style.css` - basic styling
- `script.js` - simple form confirmation message
- `reports/accessibility-audit.md` - accessibility checklist/report

## Run
Open `index.html` in a web browser.

## Git commands
```bash
git init
git add .
git commit -m "Create student activity portal structure"
git add style.css
git commit -m "Add basic page styling"
git add script.js reports/accessibility-audit.md
git commit -m "Add form interaction and accessibility report"
```

The form is a front-end demonstration only. It does not send or save student data on a server.
